# Kaia 发布

Kaia 的公开下载与更新分发仓库。这里提供发布说明和安装文件；应用源码保存在独立的私有仓库。下载公开文件无需 GitHub 登录或 GH_TOKEN。

## 当前版本

[Kaia v0.35.5 · 衣橱识别与天气缓存](https://github.com/alexyutao/kaia-releases/releases/tag/v0.35.5)

**[下载 Windows x64 完整安装包](https://github.com/alexyutao/kaia-releases/releases/download/v0.35.5/Kaia_0.35.5_x64-setup.exe)**

本次提供完整 NSIS / MSI 安装器，包含程序及所需资源，支持新安装和覆盖升级，并附更新签名与清单。安装说明见本版 Release，文件校验值见 `SHA256SUMS-0.35.5.txt`。

主要更新：视觉模型理解购买规格与尺码表的对应关系并说明依据，支持订单购买日期和数量补全；已保存图片可移除和撤销，重新导入不会恢复同一附件。首页天气按小时缓存并合并重复请求，更新失败时保留上次天气与穿衣参考。

## 从旧版升级

先从系统托盘退出 Kaia，再运行安装包。已有用户选择原安装目录即可升级，应用标识与用户数据目录保持不变；无需手动替换单个主程序。

从 v0.34.x 或更早版本升级时，会升级本机执行记录库。升级前可先导出备份；通过应用内更新安装时会创建升级快照。旧版程序无法直接打开升级后的执行记录库，如需回退，应使用升级前的备份。

其他版本、平台及附件见 [Releases](https://github.com/alexyutao/kaia-releases/releases)。旧的 v0.31.1 主程序手动替换版仍保留供历史查阅。

## 在线更新

本版使用与客户端内置公钥匹配的原私钥签名，附带 EXE / MSI 更新签名和 `latest.json`，并设为 Latest。已使用公开更新源的旧版可在「设置 → 通用 → 应用更新」检查、下载并验证更新。

仍使用私有更新源的旧版需先从上面的链接手动安装一次，之后即可使用公开更新源。

更新签名用于验证来源与完整性；本版未配置 Windows Authenticode 发布者证书，系统仍可能显示 SmartScreen 提示。

本仓库使用独立的提交历史与版本标签，应用源码不在此仓库分发。
